# Changelog

All notable changes to Cadence are recorded here. The format is kept simple on
purpose: each milestone lists the user-visible slices that landed.

## [0.1.0] - 2026-11-25

### Added

- Cargo workspace with zero external dependencies.
- Score and notation model.
- Bounded original XML parser and MusicXML import/export.
- Deterministic engraving pipeline with collision checks.
- Original SVG and PDF writers, MIDI note-event export.
- Loopback Studio with embedded HTML/CSS/JS and SSE updates.
- Fixtures, fuzz harness, benchmark harness, documentation.
